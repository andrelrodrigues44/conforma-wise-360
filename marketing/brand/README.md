# CONFORMA360 — Brand Assets

Esta pasta é o ponto oficial de organização dos ativos de marca usados pelo Marketing AI.

## Logo oficial

A fonte de verdade é a logo fornecida pelo responsável do projeto nesta etapa: escudo com folha verde + wordmark `CONFORMA360`.

### Arquivos recomendados

- `logo-conforma360-oficial.svg` — versão vetorial principal.
- `logo-conforma360-oficial.png` — versão transparente para uso digital.
- `logo-conforma360-branca.svg` — uso em fundos escuros.
- `logo-conforma360-icon.svg` — símbolo isolado.

## Regra de integridade

O agente deve utilizar um ativo oficial existente quando estiver disponível. Não deve criar uma nova logo, redesenhar o símbolo ou alterar a composição para resolver uma necessidade de layout.

## Próximo ativo

O JPG enviado nesta etapa deve ser mantido como referência visual até que o arquivo vetorial/transparente oficial seja disponibilizado no repositório.
